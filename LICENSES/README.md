# ライセンス

Lievre Term は SIL Open Font License 1.1（[OFL.txt](OFL.txt)）で配ります。元は IBM Plex Mono と IBM Plex Sans JP（どちらも OFL 1.1、予約された書体名「Plex」）で、書体名に「Plex」は使っていません。

## Nerd Fonts の記号（名前に NF の付くバリエーション）

NF の付くバリエーションには、Nerd Fonts 3.5.1 の Symbols Nerd Font Mono の記号をすべて入れています。記号は集合ごとにライセンスが違います。表は Nerd Fonts の [license-audit.md](nerd-fonts/license-audit.md) と、各集合の配布物に付いたライセンス文から作りました。本文は `nerd-fonts/` にあります。

| 集合 | 主な符号位置 | ライセンス | 本文 |
|---|---|---|---|
| Powerline Symbols | U+E0A0–E0A2, U+E0B0–E0B3 | MIT | [PowerlineSymbols-MIT.txt](nerd-fonts/PowerlineSymbols-MIT.txt) |
| Powerline Extra Symbols | U+E0A3, U+E0B4–E0D7 | MIT | [PowerlineExtraSymbols-MIT.txt](nerd-fonts/PowerlineExtraSymbols-MIT.txt) |
| IEC Power Symbols | U+23FB–23FE, U+2B58 | MIT | [NerdFonts-MIT.txt](nerd-fonts/NerdFonts-MIT.txt) |
| Pomicons | U+E000–E00A | OFL 1.1（予約名「Pomicons」） | [Pomicons-OFL.txt](nerd-fonts/Pomicons-OFL.txt) |
| Font Awesome Extension | U+E200–E2A9 | MIT | [NerdFonts-MIT.txt](nerd-fonts/NerdFonts-MIT.txt) |
| Weather Icons | U+E300–E3E3 | OFL 1.1 | [WeatherIcons-OFL.txt](nerd-fonts/WeatherIcons-OFL.txt) |

Nerd Fonts と同じく、記号はセルに合わせて大きさと位置だけを変えています（形は変えていません）。予約された書体名（Pomicons・Font Awesome）は書体名に使っていません。

U+2665 は、JP の付くバリエーションでは IBM Plex Sans JP の字形を使います。

## lievre の字形

U+E500–E509 の字形（カードの角と辺、ボタンの両端、フォーカスの括弧）は、このリポジトリで描いたもので、フォントと同じ OFL 1.1 です。
